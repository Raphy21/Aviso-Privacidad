01

Información general

Esta política de privacidad corresponde específicamente a Fishing Touch!, una aplicación desarrollada por Raphy21. Su propósito es explicar de forma sencilla cómo se trata la información al utilizar el juego.

02

Recopilación de datos personales

Fishing Touch! se puede jugar sin conexión a internet y no solicita datos personales para jugar ni transmite información personal a servidores externos.

03

Conexión a internet y servicios de terceros

El juego no necesita una conexión a internet para funcionar.

04

Almacenamiento local

Si el juego guarda datos de partida o ajustes, estos podrían permanecer en el dispositivo. Los datos locales podrían eliminarse al borrar los datos de la aplicación o al desinstalarla.

05

Servicios externos y transferencias de datos

Fishing Touch! no declara transmitir datos personales a terceros ni realizar transferencias de datos a servidores externos.

06

Privacidad de menores

El juego está indicado como apto para todo público y no solicita información personal para jugar.

07

Seguridad

Al no declararse transmisión de información personal a servidores externos, esta política no describe servidores que almacenen datos del juego.

08

Cambios en esta política

Este documento podría actualizarse si cambian las funciones, las dependencias o las prácticas de tratamiento de datos de Fishing Touch!. La fecha de actualización indicada al inicio se modificará cuando se publique una nueva versión.
